# Continue the Arctic v3 Lineage

Arctic2 will begin at version 3.7.0 as a drop-in successor to Arctic v3.7, preserving its public behavior and provider coverage under a new package name. Starting a new version line at 1.0.0 would obscure compatibility, while 4.0.0 would falsely imply a breaking redesign; future Arctic2 releases will follow strict semantic versioning rather than Arctic's former allowance for breaking provider changes in minor releases.
